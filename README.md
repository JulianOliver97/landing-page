## Projetos em destaque

### Gerador de Orçamentos Web

Sistema web desenvolvido com Python e Flask para criação e gerenciamento de orçamentos comerciais.

Principais funcionalidades:

- Cadastro de dados da empresa
- Cadastro de clientes
- Inclusão de múltiplos serviços
- Geração automática de PDF
- Numeração automática de orçamentos
- Histórico de propostas
- Visualização de orçamentos
- Edição de propostas
- Reemissão de PDF
- Exclusão de registros
- Armazenamento em banco SQLite
- Interface responsiva
- Deploy em ambiente web

Tecnologias:

- Python
- Flask
- SQLite
- JavaScript
- HTML
- CSS
- ReportLab
- Gunicorn
- Render
